# Amateur Radio Service regulatory database for the AREDN bands, in wireless-regdb
# db.txt syntax. Covers only 13 cm (2.4 GHz) and 5 cm (5.8 GHz). One stanza per
# country present in upstream wireless-regdb 2026.05.30.
#
# Field meanings (same syntax as wireless-regdb, ham semantics):
#   (start - end @ max_bw), (power)[, flags]
#   start/end  transmit edges in MHz; a channel's full width must fit inside
#   max_bw     widest channel allowed (MHz); national bandwidth caps are encoded
#              here (e.g. AT 1 MHz on 13 cm); AUTO-BW lets a channel span
#              adjacent rules, as in upstream regdb
#   power      top-licence-class transmitter limit, PEP, in mW where known
#              (*not* EIRP as upstream). (100) = no verified limit encoded.
#   A country with no rules has no 13/5 cm spectrum usable for 802.11 without
#   a special permit; the reason is in its comment.
#
# Inclusion policy: ranges usable by the top licence class without a special
# permit, for any/digital/ATV modes. Left out (and listed in each stanza's
# comment): permit-only ranges, satellite/EME/beacon-only ranges, and ranges
# whose permitted emissions are narrowband only.
#
# Each stanza says where its data came from:
#   verified (national regulation)   the regulator's own document
#   verified (DARC CEPT country list) DARC's per-country summary of national
#                                     regulations, compiled by DK5JI, 2024-06-19
#   partly verified                   some ranges confirmed, others assumed
#   ITU default                       not checked; ITU RR Article 5 allocation
#                                     for the ITU region. Treat as an upper
#                                     bound, not an authorization.
#
# Reviewed 2026-11-18.
